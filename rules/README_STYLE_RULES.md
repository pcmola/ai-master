# README 작성 규칙

> README.md 와 저장소 안 Markdown 설명 문서를 쓰거나 고치기 전에 읽는다. `AGENTS.md` 에서 연결한다.

## 문체

- 본문 문장은 `~합니다`·`~입니다` 체로 끝낸다. `~한다`·`~쓴다`·`~된다` 같은 반말 끝맺음은 쓰지 않는다.
- 표 칸은 짧은 명사형 끝맺음(`~않음`, `~포함`, `~필요`)을 써도 된다. 한 칸 안에서 명사형과 `~합니다`를 섞지 않는다.
- 같은 절 안에서 문체를 바꾸지 않는다. 고친 뒤 반말 끝맺음이 남았는지 검색한다(코드 블록·인라인 코드 제외).

## 읽기 쉽게

- 한 문장에 사실 하나. 문단은 3문장 이내로 쓰고, 넘으면 글머리로 나눈다.
- 괄호 안에 다시 괄호를 넣지 않는다. 괄호·화살표(→)·인라인 코드가 한 문장에 겹치면 문장을 나눈다.
- 화면을 이해하는 데 필요 없는 세부(트레이스 id, 커밋 해시, 측정값의 소수점)는 그림 설명에서 빼고 6·8장 같은 상세 절에 둔다.
- 줄여 쓴 말이나 내부 용어는 처음 나올 때 풀어 쓴다.

## 실행 화면(그림) 설명

- 그림마다 `**① 짧은 제목**` → 한두 줄 글머리 → 그림 순서로 쓴다. 번호는 절 안에서 순서대로 붙인다.
- 절 머리에 촬영 날짜와 "설명할 곳은 빨간 테두리"를 한 번만 적는다.
- 예시 데이터로 찍은 그림은 설명과 그림 양쪽에 예시임을 밝힌다.
- 로그 화면은 줄 형식을 `| 로그 | 의미 |` 표로 설명한다.

## 링크와 표기

- 맨 주소는 `<https://…>` 로 감싼다. 뒤 글자(`)로`, `에서`)가 링크에 붙지 않게 한다.
- 물결표(`~`)로 범위를 쓰지 않는다(취소선으로 바뀜). `20초에서 40초`처럼 쓴다.
- 식별값(IP·이메일·구독 ID·사람 이름)은 문서와 그림 모두에서 가린다. 저장소는 공개다.
